## The design in three sentences

AI **reads**: one extraction call per proposal turns the PDF into fields, and every value must come with a word-for-word quote that code then finds in the document. Fixed **rules score**: mandatory pass/fail, budget and 16-week limits, then weighted formulas the admin configures, so the same input always gives the same ranking and every point can be traced. A **human decides**: flagged bids are never ranked automatically, any result can be overridden with a reason, and everything is logged.

**Sample result:** A (92.7) ranked 1st, E (73.5) 2nd. D and C are flagged for a person (D has no committed completion date; C contains hidden text telling automated reviewers to rank it first). B is ineligible (licence held by a subcontractor, not the bidder).

## Assumptions

- The budget ceiling ($260,000) and 16-week deadline are hard project limits: over the limit = ineligible, not stated = flagged for clarification.
- "Licence held by the bidder" excludes a subcontractor's licence.
- "Monitoring plan" means post-installation system performance monitoring, not weekly progress reports.
- Proposal text is the extracted PDF text, as the brief states. No proposal text is copied into this repository; proposals are referred to by letter.
